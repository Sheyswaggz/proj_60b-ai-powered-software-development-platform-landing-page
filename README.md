# AI-Powered Software Development Platform Landing Page

A modern, high-performance landing page built with Vite, Tailwind CSS, and vanilla JavaScript. This project showcases an AI-powered software development platform with a focus on developer experience, performance, and maintainability.

## 🚀 Features

- ⚡️ **Lightning Fast** - Built with Vite for instant HMR and optimized production builds
- 🎨 **Modern Styling** - Tailwind CSS for utility-first, responsive design
- 🔍 **Code Quality** - ESLint and Prettier for consistent code formatting
- 🧪 **E2E Testing** - Playwright for reliable end-to-end testing
- 🐳 **Docker Ready** - Containerized for consistent deployment
- 🔄 **CI/CD Pipeline** - GitHub Actions for automated testing and deployment
- 📱 **Responsive Design** - Mobile-first approach for all screen sizes

## 📋 Prerequisites

- **Node.js** >= 18.0.0
- **npm** or **yarn** package manager
- **Docker** (optional, for containerized deployment)
